# Установка на Steam Deck

Займёт около 10 минут. Понадобятся Wi-Fi и клавиатура (экранная тоже подойдёт: `Steam` + `X`).

## 1. Перейдите в Desktop Mode

Кнопка `Steam` → **Питание** → **Переключиться на рабочий стол**.

## 2. Задайте пароль пользователя (если ещё не задавали)

Откройте **Konsole** (меню приложений → System → Konsole) и выполните:

```bash
passwd
```

Пароль понадобится для `sudo` и для Decky.

## 3. Установите Decky Loader

1. Откройте в браузере на Deck <https://decky.xyz> и скачайте `decky_installer.desktop`.
2. Перетащите файл из «Загрузок» на рабочий стол и запустите двойным кликом.
3. Выберите **Release**, введите пароль из шага 2 и дождитесь окончания установки.

## 4. Включите режим разработчика в Decky

1. Вернитесь в игровой режим (ярлык **Return to Gaming Mode** на рабочем столе).
2. Нажмите `...` → вкладка Decky (значок розетки) → ⚙️ **Настройки**.
3. Включите **Developer mode**. В настройках появится раздел **Developer**.

## 5. Установите плагин

### Вариант А: по ссылке (проще)

`...` → Decky → ⚙️ → **Developer** → **Install Plugin from URL**, вставьте:

```
https://zzqar.github.io/zapret-deck/z.zip
```

Ссылка всегда ведёт на последнюю версию. Чтобы обновить плагин, повторите этот шаг.

### Вариант Б: из файла

1. В Desktop Mode скачайте `zapret-deck.zip` со страницы <https://github.com/zzqar/zapret-deck/releases/latest>.
2. В игровом режиме: `...` → Decky → ⚙️ → **Developer** → **Install Plugin from ZIP File** → выберите файл из `~/Downloads`.

### Вариант В: с компьютера по SSH (для разработки)

На Deck в Konsole:

```bash
sudo systemctl enable --now sshd
```

На компьютере (нужны Node 20+ и pnpm) в папке проекта:

```bash
./deploy.sh deck@steamdeck.local
```

Если `steamdeck.local` не находится, укажите IP Deck: **Настройки** → **Интернет** → ваша сеть.

## 6. Первый запуск

1. `...` → Decky → **Zapret Deck**.
2. Нажмите **«Скачать nfqws»** и дождитесь сообщения «nfqws … установлен».
3. Включите **«Защищённый DNS»** и **«Включить»**.
4. Нажмите **«Проверить Steam»**. Все строки должны быть ✅.
5. Перезапустите Steam: `Steam` → **Питание** → **Перезапустить Steam**.

Если включён **«Автозапуск»**, после перезагрузки Deck всё поднимется само.

## Если что-то не работает

| Что видно в «Проверить Steam» | Что делать |
|---|---|
| `DNS подменён → 127.0.0.1` | Проверьте, что «Защищённый DNS» включён и без ошибки. Выключите и включите Wi-Fi. |
| ❌ при нормальном IP | Выберите другую стратегию `VN · …` и проверьте снова. Повторяйте, пока не будет ✅. |
| «nfqws завершился сразу после запуска» | Откройте «Показать лог». Обычно стратегию не принял nfqws: нажмите «Обновить nfqws». |
| Сайт стал работать хуже | Добавьте его домен в `/home/deck/zapret-deck/lists/exclude.txt` и нажмите «Перезапустить nfqws». |

Если не открывается конкретный сайт, допишите его домен в `/home/deck/zapret-deck/lists/vietnam.txt`. Можно просто обновить страницу 2–3 раза: автосписок добавит его сам.

Проверка из Konsole:

```bash
sudo nft list table inet zapret_deck
```

```bash
nmcli -g IP4.DNS device show wlan0
```

Вторая команда должна вывести `127.0.0.77`.

## Удаление

`...` → Decky → ⚙️ → **Плагины** → Zapret Deck → **Удалить**. Правила firewall и DNS вернутся к исходным. Папку с настройками можно удалить вручную:

```bash
rm -rf ~/zapret-deck
```
